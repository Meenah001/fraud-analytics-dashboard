# Fraud Analytics Dashboard (2021–2025)

# Project Background

Fraud remains a growing financial risk across industries.
This project analyzes confirmed fraud cases between 2021 and 2025 to identify trends, high-risk fraud types, and geographic concentration areas.

The goal was to move beyond simple totals and uncover patterns in fraud severity and distribution.

# Key Insights

Fraud complaint volume declined over time.

Financial losses remained high despite a reduction in case volume.

Average loss per complaint increased significantly.

Investment fraud generated the highest financial impact.

Identity fraud recorded the highest complaint volume.

Certain regions contributed disproportionately to total losses.

# Business Question:

How has fraud volume and financial impact evolved?

# What This Dashboard Shows:

Total fraud cases

Total financial loss

Average loss per complaint

Year-over-year trend analysis

# Key Insight:

Although total fraud complaints declined over the five years, the average loss per complaint increased significantly.
This indicates that fraud cases are becoming fewer but more financially severe.

# Business Implication:

Organizations may need to shift focus from handling volume to managing high-severity fraud cases that generate larger financial impact.

Which fraud types pose the greatest financial risk?

# What This Dashboard Shows:

Top fraud types by total financial loss

# Key Insight:

Identity fraud had the highest number of cases, but investment fraud generated the highest financial loss per case.
This highlights the difference between high-frequency and high-severity fraud.

# Business Implication:

Fraud prevention strategies should prioritize not only case volume but also financial severity to allocate resources effectively.
